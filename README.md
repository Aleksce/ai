# 🔥 Tinder Trainer: Nastya Edition

Игровой тренажёр диалогов с ИИ-персонажем. Работает как Telegram Web App и на GitHub Pages.

---

```
│   ├── game.js         — Игровая логика
│   ├── ui.js           — UI-менеджер
│   └── app.js          — Инициализация
└── .nojekyll           — Нужен для GitHub Pages
```

## ⚡ Быстрый старт

### 1. Настройка API ключа

Открой файл `js/config.js` и вставь ключ:

**Вариант A — Gemini (бесплатно, онлайн):**
1. Получи ключ на https://aistudio.google.com/app/apikey
2. В `config.js` установи:
   ```js
   AI_PROVIDER: 'gemini',
   GEMINI_API_KEY: 'твой_ключ_здесь',
   ```

**Вариант B — Ollama (локально, бесплатно):**
1. Установи Ollama: https://ollama.com
2. Запусти: `ollama run llama3` (или другую модель)
3. В `config.js` установи:
   ```js
   AI_PROVIDER: 'ollama',
   OLLAMA_MODEL: 'llama3',
   ```
4. ⚠️ При запуске через Telegram нужен туннель к localhost:11434 (ngrok, cloudflared)

### 2. Загрузка на GitHub Pages

1. Создай репозиторий на GitHub
2. Загрузи все файлы в корень репозитория
3. Зайди в Settings → Pages → Source: main branch / root
4. Через минуту сайт доступен по: `https://<username>.github.io/<repo>/`

### 3. Подключение Telegram Web App

1. Открой @BotFather в Telegram
2. `/newbot` — создай бота
3. `/newapp` → выбери бота → укажи URL из GitHub Pages
4. Готово! Открывай через кнопку в боте

## 💾 Датасеты

Все диалоги сохраняются в **localStorage** браузера.

- 👍 **Идеал** → `dataset_good` в localStorage
- 👎 **Косяк** → `dataset_bad` в localStorage (с причиной ошибки)

**Экспорт:** Нажми кнопку «↓ Экспорт датасета (JSON)» в главном меню → скачается JSON-файл с обоими датасетами.

Файл содержит:
```json
{
  "good": [...],
  "bad": [...],
  "stats": {...},
  "exportedAt": "2026-..."
}
```
